Information

This is a simple Ceaser cipher encoder/decoder that uses a password to generate a seed for the cipher. The seed is used to shuffle the alphabet, creating a unique cipher for each password.
The code for this was originally written in python, but I wanted to make it available in the browser, so I got an AI I made sure that the python code and the javascript code produced the same results for the same inputs.
That is why the website is vibecoded and looks like that, but all original python code was written by me.
