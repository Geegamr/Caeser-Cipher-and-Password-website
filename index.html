About this tool

This site is a 1-to-1 re-implementation of My Encrypt.py in HTML + CSS + JS — a Caesar-style substitution cipher over a 66-character alphabet, ordered deterministically from a password using CPython's random.seed() and random.shuffle().

Everything runs 100% client-side. No text, files, or passwords ever leave your machine. It even works offline as a file:// page.

Compatibility guarantee

The engine reproduces CPython's Mersenne Twister seeding exactly: utf8(password) + SHA-512(password) → big-int → little-endian 32-bit words → init_by_array → Fisher–Yates with getrandbits. It is certified byte-for-byte against Python 3.14.3, so anything this site encrypts can be decrypted by the Python CLI with the same shift & password — and vice-versa.

How it's built

  • sha512.js — pure-JS SHA-512 (works offline / from file://).
  • mt19937.js — Mersenne Twister + CPython-compatible seeding & shuffle.
  • encrypt.js — the cipher engine.
  • vectors.js — reference vectors generated by the real Python script.
